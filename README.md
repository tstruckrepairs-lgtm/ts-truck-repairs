# TS Truck Repairs - Website

Professional truck repair services website built with Next.js, TypeScript, and modern web technologies.

## Features

- ✅ Professional design with dark theme and cyan accents
- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ Contact form with quote requests
- ✅ Service showcase
- ✅ Why Choose Us section
- ✅ SEO optimized
- ✅ Fast performance with Next.js

## Getting Started

### Prerequisites
- Node.js 16+ installed
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/tstruckrepairs-lgtm/ts-truck-repairs.git
cd ts-truck-repairs

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

### Deploy to Vercel (Recommended)

The easiest way to deploy is with [Vercel](https://vercel.com):

1. Push your code to GitHub
2. Connect your GitHub repository to Vercel
3. Vercel automatically deploys on every push

```bash
# Alternative: Deploy via Vercel CLI
npm i -g vercel
vercel
```
